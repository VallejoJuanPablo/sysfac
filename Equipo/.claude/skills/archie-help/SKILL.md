# /archie-help

Lee el archivo `archie-help.md` (en la raíz de Equipo) y presentá su contenido al usuario de forma clara y organizada.

## Instrucciones
1. Leé el archivo `archie-help.md` usando la herramienta Read
2. Presentá el contenido tal cual está, respetando las secciones y tablas
3. Si el usuario pide una sección específica (ej: `/archie-help agentes`), mostrá solo esa sección
4. Si el usuario pide una sección específica (ej: `/archie-help sdd`), mostrá solo esa sección
5. Siempre respondé en español
