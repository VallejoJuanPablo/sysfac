# Plantilla — Informe

## Formato estándar

```markdown
# Informe: [Título]

- **Fecha:** [YYYY-MM-DD]
- **Agente:** [área/agente]
- **Tipo:** [resumen | investigación | análisis | plan]

## Resumen
[2-3 líneas que expliquen qué se hizo y el resultado principal]

## Detalle
[Desarrollo completo del trabajo realizado]

## Decisiones tomadas
- [Decisión]: [Motivo]

## Próximos pasos
- [ ] [Acción pendiente 1]
- [ ] [Acción pendiente 2]

## Archivos creados o modificados
- [ruta/archivo] — [qué se hizo]
```
